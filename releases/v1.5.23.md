# Codex汉化增强版 v1.5.23

本版本继续提升 Windows 桌面端的安装、自动更新与界面稳定性。

- 修复汉化增强版设置入口在较长原生设置列表中不可见的问题，并保持入口位于左侧设置栏下部。
- 优化大包下载、异常重试与安装优先级，减少更新中断后重复下载或等待过久。
- 加强安装器、后台服务和内置运行资源的版本一致性校验。
- 改进自动更新完成后的服务接管、快捷方式与后续更新能力检查。
- 本次按已验证的兼容范围分批投放自动更新，后续批次会依据实际运行结果继续推进。

普通用户请下载 Windows 安装器；它是可供新用户首次安装及现有用户修复安装的完整安装包。预编译更新资产由自动更新通道使用，无需手动解压。
